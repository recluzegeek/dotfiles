# Editor Ergonomics

## Philosophy

Improve Vim defaults without replacing Vim's editing model.

## Movement

| Key         | Action           |
| ----------- | ---------------- |
| Alt+j       | Move line down   |
| Alt+k       | Move line up     |
| Alt+Shift+j | Duplicate        |
| Alt+Shift+k | Duplicate upward |

## Clipboard

Visual paste uses:

"_dP

This preserves the yank register when replacing selections.

## Search

Search navigation keeps the cursor centered:

n
N *
