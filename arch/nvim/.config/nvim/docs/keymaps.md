# keymaps

Leader: Space

## Find

| Mapping      | Action       |
| ------------ | ------------ |
| `<leader>ff` | Find files   |
| `<leader>fg` | Live grep    |
| `<leader>fb` | Buffers      |
| `<leader>fr` | Recent files |

## LSP

| Mapping      | Action            |
| ------------ | ----------------- |
| `<leader>sd` | Document symbols  |
| `<leader>sD` | Workspace symbols |

## Git

| Mapping      | Action   |
| ------------ | -------- |
| `<leader>gs` | Status   |
| `<leader>gb` | Branches |
