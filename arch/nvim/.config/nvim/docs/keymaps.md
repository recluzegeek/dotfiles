# Keymaps

Leader:

Space

## Navigation

| Key        | Action       |
| ---------- | ------------ |
| <leader>ff | Find files   |
| <leader>fg | Live grep    |
| <leader>fb | Find buffers |
| <leader>fh | Search help  |

## Workspace

| Key        | Action   |
| ---------- | -------- |
| <leader>e  | Explorer |
| <leader>tt | Terminal |

# LSP Keymaps

These mappings only exist after a language server attaches to the current buffer.

| Key        | Action              | Equivalent        |
| ---------- | ------------------- | ----------------- |
| gd         | Go to definition    | VS Code F12       |
| gr         | Find references     | VS Code Shift+F12 |
| K          | Hover documentation | VS Code hover     |
| <leader>rn | Rename symbol       | VS Code F2        |
| <leader>ca | Code action         | VS Code Ctrl+.    |
